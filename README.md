# Tarushv's CP Tips 🚀

A responsive, modern website dedicated to Competitive Programming resources, tips, and strategies. Features a clean interface with both light and dark mode support.

## 📋 Features

- **Responsive Design**: Optimized for all screen sizes
- **Dark/Light Mode**: Toggle between themes for comfortable viewing
- **Animated Elements**: Smooth fade-in animations for better user experience
- **Resource Directory**: Comprehensive collection of CP platforms and learning materials
- **Tips & Strategies**: Curated advice for competitive programmers
- **Modern UI**: Clean, card-based layout with hover effects

## 🛠️ Technical Stack

- HTML5
- CSS3 (with modern features like Flexbox and CSS Grid)
- Vanilla JavaScript
- Custom CSS animations
- Mobile-first responsive design

## 📱 Responsive Features

- Fluid typography
- Flexible card layouts
- Adaptive navigation
- Mobile-optimized spacing
- Responsive header adjustments

## 🎨 Design Features

### Light Mode
- Clean, light background (#f0f0f0)
- Gradient header (purple to blue)
- White cards with subtle shadows
- Accessible text contrast

### Dark Mode
- Dark background (#121212)
- Dark gradient header
- Dark cards (#1e1e1e)
- Light text for contrast

## 🚀 Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. No build process required - pure HTML/CSS/JS

## 💻 Usage

The website can be used directly from any modern web browser. The dark mode toggle is accessible via the button in the top-right corner.

## 🔧 Customization

### Adding New Sections
Add new sections following this structure:
```html
<section id="your-section">
  <h2>Section Title</h2>
  <div class="content">
    <div class="card">
      <h3>Card Title</h3>
      <!-- Content -->
    </div>
  </div>
</section>
```

### Modifying Styles
The CSS is organized into sections:
- CSS Reset
- Base styles
- Component styles
- Dark mode styles
- Animations
- Media queries
